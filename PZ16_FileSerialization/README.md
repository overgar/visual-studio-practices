# ПЗ16 — последовательная обработка файла `people.xml`

Отдельный проект Visual Studio для задания № 1 из `пз16.pdf`.

## Запуск

Откройте `PZ16_FileSerialization.csproj` в Visual Studio или выполните из этой папки:

```text
dotnet run
```

Проект загружает XML-массив учеников из `people.xml`, выводит меню команд 0–4 и повторяет его до выбора выхода.

## Реализовано

- десериализация массива `Person[]` через `XmlSerializer`;
- показ лучшего и худшего ученика по среднему арифметическому пяти оценок;
- показ списка в формате примера из методички;
- фильтр учеников, у которых средний балл строго больше введённого порога (порог читается от пользователя, так как в PDF его значение не задано);
- проверка наличия файла и ровно пяти оценок у каждой записи.

При равенстве средних баллов выбирается первый ученик в XML. В приложенном PDF указаны четыре действия, хотя в начале сказано «одну из трех команд»; выполнены все четыре действия и пункт выхода 0 из примера меню.

## Проверка

Сборка решения `PZ16_FileSerialization.sln` завершилась без ошибок и предупреждений. Прогнаны команды 1–4: выбран лучший и худший ученик, выведены все пять записей, фильтр при пороге 4,2 вернул только учеников со средним баллом выше порога. Проверено копирование `people.xml` в выходную папку сборки.
