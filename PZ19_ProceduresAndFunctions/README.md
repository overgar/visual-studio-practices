# ПЗ19 — организация процедур и функций

Консольное приложение Visual Studio с меню из 28 заданий: 14 задач первой подгруппы и 14 задач второй подгруппы из `PZ19_-_RP_organizatsia_protsedur_i_funktsiy.pdf`.

## Запуск

Откройте `PZ19_ProceduresAndFunctions.sln` в Visual Studio или выполните:

```text
dotnet run
```

Введите номер задания 1–28, затем параметры. Для выхода введите 0. Проверка основных алгоритмов без ручного ввода:

```text
dotnet run -- --selftest
```

## Что реализовано

Первая подгруппа: квадратное уравнение, формула Герона, произведения (тремя циклами), суммы геометрических прогрессий, `cos` и `tg` через ряды, НОД для двух функций, бином Ньютона, конвертор валют через `switch`, переводы систем счисления, числа Фибоначчи и золотое сечение.

Вторая подгруппа: сортировка 3D-точек и расстояния, анализ многоугольника, построение простого многоугольника и непересекающихся пар, комплексные числа, правильный многоугольник, прямоугольники, ломаные по цветам, минимальный сегмент, охватывающий прямоугольник, звёздный каталог, подобные треугольники, правильные многоугольники и сортировка по приоритету координат.

## Принятые допущения

- Для простого многоугольника используется сортировка точек по полярному углу вокруг центра масс и устранение оставшихся пересечений 2-opt; результат проверяется.
- Непересекающиеся пары строятся соединением соседних точек после сортировки по `X`, затем по `Y`; отсутствие пересечений проверяется.
- Ориентация прямоугольника считается горизонтальной, если ширина не меньше высоты.
- Курсы валют в конверторе условные, учебные.
- В PDF задачи даны по вариантам; приложение содержит все варианты обеих подгрупп.
