# ПЗ27 — SimpleNotepad с сохранением и печатью документа

Windows Forms приложение Visual Studio по методичке ПЗ27. Несмотря на заголовок PDF («Разработка приложения WPF…»), практическая часть описывает доработку приложения **SimpleNotepad** в Windows Forms: добавление сохранения документа, параметров страницы, предварительного просмотра и печати. Работа выполнена по тексту задания.

## Запуск

Откройте `PZ27_SimpleNotepadPrint.sln` в Visual Studio и нажмите F5 или выполните:

```text
dotnet run
```

Автопроверка:

```text
dotnet run -- --selftest
```

## Что добавлено по сравнению с ПЗ26

- компонент `PrintDocument` с именем документа `SimpleNotepad Document`;
- пункт **File → Page Setup…** — `PageSetupDialog` (размер и ориентация бумаги, поля);
- пункт **File → Print Preview…** — `PrintPreviewDialog` с постраничным выводом;
- пункт **File → Print…** (`Ctrl+P`) — `PrintDialog` и печать;
- собственный постраничный вывод текста `TextPrinter.DrawNextPage`: текст разбивается на страницы по высоте области печати, перенос строк учитывает ширину страницы;
- сохранение документа в `RTF` и `TXT`, сохранение как, подтверждение несохранённых изменений (как в ПЗ26).

## Структура

| Файл | Назначение |
| --- | --- |
| `Program.cs` | точка входа, режим `--selftest` |
| `MainForm.cs` | окно редактора, меню, панель инструментов, печать |
| `TextPrinter.cs` | постраничный вывод текста в `Graphics` |
| `EditorFile.cs` | вспомогательные методы чтения/записи текста |
| `SelfTest.cs` | автоматическая проверка функций, включая разбиение на страницы |

## Самопроверка

`dotnet run -- --selftest` проверяет сохранение и чтение `TXT`/`RTF`, имя печатаемого документа, разбиение длинного текста минимум на две страницы (через `PreviewPrintController`), наличие меню, `RichTextBox`, строки состояния и пунктов печати в меню **File**. Все 11 проверок проходят.
