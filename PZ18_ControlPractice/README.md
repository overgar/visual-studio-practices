# ПЗ18 — контрольная практическая работа

Отдельное консольное решение Visual Studio с меню для всех 24 заданий на первой странице `PZ18_-_RP_generiruyuschego_sluchaynye_chisla.pdf`.

## Открытие и запуск

Откройте `PZ18_ControlPractice.sln` в Visual Studio или выполните:

```text
dotnet run
```

Введите номер задания 1–24, затем его параметры. Для выхода введите 0. Результаты задач 19 и 23, если число найденных значений разумно для полного вывода, сохраняются в папке `Results`.

## Принятые допущения из-за неполных условий

- Площадь под графиком в заданиях 3, 5 и 16 считается геометрической площадью (интегрируется модуль функции) составным методом трапеций; конечная неполная часть интервала также учитывается.
- Для графиков без заданного диапазона используются `[-2π, 2π]` (синус), `[0, 5τ]` (экспонента) и `[-5, 5]` (парабола).
- Счастливый билет имеет чётное число цифр и допускает ведущие нули; равны суммы цифр двух половин.
- Для задания 14 первая положительная полуволна берётся от `t=0` до первого нуля после фазы α.
- Для задания 15 точность понимается как абсолютная погрешность площади с консервативным 95%-м доверительным запасом Монте-Карло.
- Перечень контрольных вопросов в PDF отсутствует. Ответы и неуказанные числовые входы не выдумываются.
