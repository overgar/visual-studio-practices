# ПЗ23 — запись данных формы в текстовый файл

Windows Forms приложение Visual Studio по `PZ23_-_RP_programmirovanie_prilozheniy.pdf`.

## Запуск

Откройте `PZ23_InsuranceFile.sln` в Visual Studio и нажмите F5 или выполните:

```text
dotnet run
```

Автопроверка:

```text
dotnet run -- --selftest
```

## Что делает форма

Форма содержит поля фамилии и имени, адреса (город, улица, дом, квартира), пола, срока страхования (`NumericUpDown`) и вида страхования (`ComboBox`), а также надпись для сообщения об ошибке. Кнопка OK проверяет заполнение всех полей. Если чего-то не хватает, появляется надпись «Не все данные введены!» и файл не изменяется. Если всё заполнено, запись **дописывается** в файл `Страхователи.txt` в папке запуска (`bin\Debug\net10.0-windows`), выводится `MessageBox`, поля очищаются. Кнопка «Отмена» закрывает форму.

Путь к созданному файлу показан внизу формы. Формат записи соответствует методичке: страхователь, адрес, пол, срок, вид страхования, разделитель.
