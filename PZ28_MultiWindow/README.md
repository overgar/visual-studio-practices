# ПЗ28 — многооконные SDI- и MDI-приложения

Windows Forms решение Visual Studio по методичке ПЗ28. В заголовке PDF указана тема «Разработка приложения WPF…», однако практическая часть посвящена **многооконным приложениям Windows Forms (SDI и MDI)** — работа выполнена по тексту задания.

В решении два самостоятельных проекта:

| Проект | Тип | Назначение |
| --- | --- | --- |
| `PZ28_SDI` | SDI-приложение | несколько независимых форм |
| `PZ28_MDI` | MDI-приложение | главная форма-контейнер и подчинённые окна |

## Запуск

Откройте `PZ28_MultiWindow.sln` в Visual Studio, выберите нужный проект как автозапускаемый и нажмите F5. Либо из командной строки:

```text
dotnet run --project PZ28_SDI\PZ28_SDI.csproj
dotnet run --project PZ28_MDI\PZ28_MDI.csproj
```

Автопроверка:

```text
dotnet run --project PZ28_SDI\PZ28_SDI.csproj -- --selftest
dotnet run --project PZ28_MDI\PZ28_MDI.csproj -- --selftest
```

## PZ28_SDI

Состав приложения по заданию:

- **главная форма** — содержит только меню: `File → Quit`, `Windows → New`, `Windows → Open Dialog`, `Help → About`;
- **форма режимов работы** (`ModeForm`) — радиокнопки `rB1` («числа больше заданного») и `rB2` («числа меньше заданного»), кнопки выбора `cB1` («Сумма») и `cB2` («Произведение»), строка редактирования `textBox1` для задания значения, кнопка «Скрыть» (`Hide()`);
  - у формы убрана кнопка закрытия (`ControlBox = false`);
  - положение задаётся вручную (`StartPosition = Manual`, `Location`);
  - элементы объявлены `public`, поэтому доступны из других форм;
- **форма «О программе»** (`AboutForm`) — кнопка OK закрывает форму;
- **форма ввода и вывода результата** (`InputResultForm`) — ввод массива одной строкой, кнопка «Вычислить»; в зависимости от состояния радиокнопок отбираются числа больше или меньше заданного, в зависимости от кнопок выбора считается сумма и/или произведение; результат выводится на форму.

В момент запуска показываются главная форма и форма режимов (в обработчике `OnShown`), остальные формы открываются из меню. Форма ввода получает ссылку на форму режимов через поле `f22`.

## PZ28_MDI

- главная форма является MDI-контейнером (`IsMdiContainer = true`) и содержит только меню;
- меню: **Файл → Выход**; **Окно → Создать, Каскад, Мозаика горизонтально, Мозаика вертикально, Закрыть текущее, Закрыть все, Единственная форма**; **Диалог → Открыть**; **Помощь → О программе**;
- **диалог настроек** (`SettingsDialog`) — те же радиокнопки, кнопки выбора и строка редактирования (`rB1`, `rB2`, `cB1`, `cB2`, `tB1`); при открытии получает текущие значения, по OK сохраняет их, по CANCEL закрывается без сохранения;
- значения диалога хранятся в статических полях главной формы (`rgi`, `b1`, `b2`, `s1`), поэтому не теряются после уничтожения окна; начальные значения задаются в `InitializeSettings()` (аналог обработчика `Load`);
- **многократно создаваемое дочернее окно** (`ChildForm`) — создаётся пунктом «Создать», имеет собственное меню «Действие», которое объединяется с меню главного окна;
- **окно в единственном экземпляре** (`SingleForm`) — при открытии пункт «Единственная форма» блокируется, в обработчике `FormClosed` снова разблокируется;
- управление окнами — стандартными средствами MDI (`LayoutMdi`, `ActiveMdiChild`, `MdiChildren`).

## Самопроверка

`--selftest` проверяет логику отбора/суммы/произведения, структуру меню, свойства форм, загрузку и сохранение настроек диалога, создание дочерних окон и блокировку/разблокировку пункта «Единственная форма»:

- PZ28_SDI — 28 проверок;
- PZ28_MDI — 35 проверок.

Обе сборки проходят без ошибок и предупреждений.
