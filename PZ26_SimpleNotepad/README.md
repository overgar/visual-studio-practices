# ПЗ26 — создание приложения SimpleNotepad

Windows Forms приложение Visual Studio по методичке ПЗ26 (текстовый редактор SimpleNotepad).

## Запуск

Откройте `PZ26_SimpleNotepad.sln` в Visual Studio и нажмите F5 или выполните:

```text
dotnet run
```

Автопроверка:

```text
dotnet run -- --selftest
```

## Возможности

- главное окно с `RichTextBox`, строкой меню, панелью инструментов и строкой состояния;
- меню **File**: создать, открыть, сохранить, сохранить как, выход;
- меню **Edit**: отмена, повтор, вырезать, копировать, вставить, удалить, выделить всё;
- меню **Format**: выбор шрифта через `FontDialog`, перенос по словам;
- меню **Help**: «О программе»;
- открытие и сохранение документов в форматах `RTF` и `TXT` (`RichTextBox.LoadFile`/`SaveFile`);
- панель инструментов: создание, открытие, сохранение, отмена/повтор, работа с буфером обмена, полужирный/курсив/подчёркивание;
- строка состояния: имя файла, позиция курсора (строка и столбец), количество символов;
- заголовок окна показывает имя файла и признак несохранённых изменений `*`;
- подтверждение сохранения при закрытии документа и приложения.

## Структура

| Файл | Назначение |
| --- | --- |
| `Program.cs` | точка входа, режим `--selftest` |
| `MainForm.cs` | окно редактора, меню, панель инструментов, строка состояния |
| `EditorFile.cs` | вспомогательные методы чтения/записи текста |
| `SelfTest.cs` | автоматическая проверка основных функций |

## Самопроверка

`dotnet run -- --selftest` проверяет сохранение и чтение `TXT` и `RTF`, наличие меню, `RichTextBox` и строки состояния, а также набор пунктов меню.
