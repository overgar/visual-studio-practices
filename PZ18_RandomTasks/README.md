# ПЗ18 — контрольная практическая работа (24 задачи)

Отдельное консольное приложение Visual Studio по всем 24 задачам из практической части `PZ18_-_RP_generiruyuschego_sluchaynye_chisla.pdf`.

## Открытие и запуск

Откройте `PZ18_RandomTasks.sln` в Visual Studio или выполните в этой папке:

```text
dotnet run
```

В главном меню выберите номер 1–24; для выхода — 0. Функции печатают ASCII-графики, результаты Монте-Карло сопровождаются оценкой стандартной ошибки/95%-й погрешности, а большие списки заданий 19 и 23 сохраняются в файлы в текущей рабочей папке после подтверждения.

## Явные допущения из-за неполных условий

- Для задач 1, 3, 5 и 16 интервал и шаг вводятся; площадь считается геометрической (интегрируется |f(x)|) методом трапеций, включая последний неполный шаг.
- Для экранных графиков 8, 13 и 18 выбран диапазон x: два периода для синусоиды, [0; 5τ] для экспоненты, [-10; 10] для параболы. В задании диапазоны не указаны.
- Для Монте-Карло задачи 15 точность трактуется как абсолютная погрешность площади с приближённым 95%-м доверительным интервалом. Задачи 7, 11 и 14 получают заданное число итераций и показывают ошибку оценки.
- В задаче 20 автоматически выбирается действительный корень кубического уравнения; применяется ограниченный методом Ньютона шаг внутри интервала изоляции.
- Для перечислений в задачах 19 и 23 приложение заранее считает количество ответов и просит подтверждение, если строк будет более 1 000 000.
- PDF не указывает, какую задачу выполнять, поэтому после уточнения выполнены все 24.

## Проверка

Сборка и отдельные проверки всех 24 пунктов выполняются перед отметкой работы завершённой.
