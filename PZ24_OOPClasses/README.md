# ПЗ24 — классы ООП: свойства, методы, события

Windows Forms приложение Visual Studio по `PZ24_-_RP_ispolzuyuschego_klassy_OOP_svoystva_metody_sobytia.pdf`.

## Запуск

Откройте `PZ24_OOPClasses.sln` в Visual Studio и нажмите F5 или выполните:

```text
dotnet run
```

Автопроверка:

```text
dotnet run -- --selftest
```

## Упражнение «Управление размерами и цветом формы»

- `ComboBox` цвета: красный, зелёный, синий, жёлтый, исходный.
- `ComboBox` размера: 500×150, 550×200, 600×250, 650×300, исходный.
- Кнопка 1 разрешает и запрещает изменение свойств формы.
- Кнопка 2 перекрашивает форму в жёлтый цвет **без ограничений**, как сказано в задании.
- Метка показывает выбранный цвет/размер и состояние ограничений.

## Задания ООП

На вкладке «Задания ООП 1–3» реализованы:

1. Абстрактный класс `Figure` с методами площади, периметра и вывода информации; производные `Rectangle`, `Circle`, `Triangle`; массив фигур и полный вывод.
2. Класс `Buyer` (ФИО, адрес, карта, счёт) с конструктором, методами установки/получения и вывода; массив покупателей, сортировка по алфавиту и фильтр по диапазону номера карты.
3. Класс `Subscriber` (номер, ФИО, адрес, карта, дебет, кредит, время междугородних и городских переговоров); фильтры по времени и алфавитный список.
