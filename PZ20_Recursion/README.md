# ПЗ20 — рекурсивные функции

Консольное приложение Visual Studio по `PZ20_-_RP_s_primeneniem_rekursivnykh_funktsiy.pdf`.

## Запуск

Откройте `PZ20_Recursion.sln` в Visual Studio или выполните:

```text
dotnet run
```

Пункт 1 — основное задание: сумма последовательности целых чисел, оканчивающейся нулём, без использования циклов. Пункты 2 и 3 дополнительно показывают рекурсивные факториал и числа Фибоначчи и сравнивают их с циклическими реализациями.

Автопроверка:

```text
dotnet run -- --selftest
```

## Реализация

- `Recursion.SumRecursive` — базовый случай при конце последовательности, иначе `число + SumRecursive(остаток)`.
- `Recursion.Factorial` — базовый случай `0! = 1`.
- `Recursion.Fibonacci` — базовые случаи `F0 = 0`, `F1 = 1`.
- Для больших значений используются `BigInteger`, поэтому переполнение не возникает.
