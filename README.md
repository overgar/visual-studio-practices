## Общие замечания

- Все GUI-проекты используют Windows Forms (`net10.0-windows`), консольные — `net10.0`.
- В каждом проекте есть автоматическая самопроверка без ручного ввода:
  `dotnet run --project <проект>.csproj -- --selftest`.
- Сборка всех решений проходит без ошибок и предупреждений.
- В ПЗ26–ПЗ28 заголовки PDF говорят о WPF, но практическая часть описывает Windows Forms (SimpleNotepad и многооконные приложения), поэтому работы выполнены по тексту практической части.
