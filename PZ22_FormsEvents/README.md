# ПЗ22 — события компонентов и связи между формами

Windows Forms приложение Visual Studio по `PZ22_-_RP_ispolzuyuschego_sobytia_komponentov_elementov_upravlenia.pdf`.

## Запуск

Откройте `PZ22_FormsEvents.sln` в Visual Studio и нажмите F5 или выполните:

```text
dotnet run
```

Автопроверка без открытия окон:

```text
dotnet run -- --selftest
```

## Состав первой формы

- 4 `TextBox`: фамилия, имя, адрес, многострочное примечание;
- 3 `GroupBox`: личные данные, адрес, дополнительные сведения;
- 2 `Button`: «Добавить фото», «Показать данные»;
- `DateTimePicker`, `CheckBox`, `ComboBox` с вариантами «Мужской»/«Женский»;
- `OpenFileDialog` с фильтром только `.jpg`, `.jpeg`, `.png`;
- `PictureBox` для предпросмотра фотографии.

## Логика

При нажатии «Добавить фото» открывается `OpenFileDialog` с ограничением типов файлов. Кнопка «Показать данные» проверяет все поля, кроме checkbox, и наличие фотографии. Если чего-то не хватает, выводится сообщение, а вторая форма не открывается. Если всё заполнено, открывается `Form2`, которая через `Owner` читает данные первой формы, показывает их и фотографию. Кнопка «Записать в форму 1» передаёт изменённое примечание обратно — обмен данными работает в обе стороны, как в методичке.
