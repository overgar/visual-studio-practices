# ПЗ17 — работа с файлами

Отдельный консольный проект Visual Studio по трём заданиям из `пз17.pdf`.

## Запуск

Откройте `PZ17_FileTasks.sln` в Visual Studio или запустите из этой папки:

```text
dotnet run
```

При запуске без аргументов программа читает `sample.txt` из папки приложения; выходные файлы `numbers.txt` и `colors.txt` записывает в текущую рабочую папку. Можно передать свои пути: сначала путь к входному текстовому файлу, затем папку для результатов.

## Что делает программа

1. Создаёт `numbers.txt` с натуральными числами от 1 до 500 через запятую.
2. Записывает `red`, `green`, `black`, `white`, `blue` в `colors.txt`, по одному значению в строке.
3. Находит длину самой длинной строки во входном текстовом файле. В комплекте использован `sample.txt`; в Visual Studio можно подставить любой другой текстовый файл аргументом запуска.

Файл для задания 3 выбран как допустимый «любой текстовый файл» из условия. Длина строки считается по `string.Length` в .NET.

## Проверка

Сборка решения `PZ17_FileTasks.sln` успешна: 0 ошибок и 0 предупреждений. Проверено, что `numbers.txt` содержит ровно 500 чисел 1–500, `colors.txt` содержит пять заданных строк, а программа для тестового `sample.txt` сообщает длину максимальной строки 78 символов.
